## 关键结论

- **陕西行测 11 年完整**：`行测真题库-xingcezhenti/` 中 `01-政治理论` ~ `06-资料分析`
  六个模块目录下各有 `2016/2017/2018/2019/2020/2021/2022/2023/2024/2025/2026年…陕西…md`，
  每题含 `**答案**：X` 与官方解析；2026 卷答案已同步导出到 `2026补充/`。
- **PDF 原卷**：`行测/`（2022–2025 网盘直下）+ AAT 合集的 `省考以及市考/陕西省考/`（2008–2022）。
- **申论**：2022–2025 七套 PDF 齐；**2026 申论 B/C 卷暂缺全文**（book118 反爬 / renrendoc 预览截断，见排障记录）。
- `行测/2026…` 若需纸质卷可由 md 题库排版打印；答案以 `2026补充/` 为准。

## 使用建议（对应复习计划）

1. **日常隐蔽刷题（上班）**：md 题库按模块出题（AI 对话纯文字），对答案看 `**答案**` 行。
2. **周末模考**：`行测/` 或 AAT 合集挑一年陕西卷，严格 9:00–11:00 计时。
3. **申论**：`申论/` 真题套卷；小题专项用 `申论题库-gongkao-tiku/` 按题型刷。
4. **资料分析/判断推理弱项**：`考点标注-判断推理资料分析/` 按考点走。
5. **本地刷题系统**（可选）：`刷题App-kaogong-shuati/README.md`，需 Node ≥22.5，
   `node tools/reassemble-tiku.mjs` 重组 tiku.db 后启动。
